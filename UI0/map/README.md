# UI0 地図・記録画面

UI0の全機能と画面構成を基準にし、UI4のデザインだけを`../ui4-theme.css`で適用しています。UI4の不完全なAPI処理・認証・ナビゲーションは取り込んでいません。

最終確認日: 2026-08-29

## 役割

Leaflet地図、現在地追従、GPS生座標とaccuracyの収集、ブラウザ内マップマッチング、点字ブロックの保存・OSM公開・本人取消し、点字ブロック/道情報表示、PROタグとひとことメモを担当します。

## 通常フィッティング

`osm-browser-matcher.js`は`/api/osm-walkable-network`から現在地周辺約1kmの道路・歩道を取得します。取得中心から約650m移動すると追加取得します。歩道を優先し、前後点、accuracy、直前Way、既存Wayの接続関係から連続経路を確定します。低精度点は前後と矛盾しない場合だけ補間し、確定できない点は捨てます。

通常記録にValhallaは使いません。旧Valhalla比較・診断UIとその処理はUI0から削除済みです。既存点字ブロック表示は約10kmで、1kmのフィッティング網とは別です。OSM送信・取消し成功後は道路網と表示データを更新します。

## 保存

`async-record-queue.js`がIndexedDBへジョブを保存し、セッション開始、経路保存、終了、タグ・メモ、OSM変更案、公開、ネットワーク更新を順に行います。一時的な通信失敗は再試行し、冪等性キーで二重送信を防ぎます。

OSMへは公開対象の点字ブロックタグだけを送り、本人限定タグとメモはPostgreSQLだけに保存します。他人は記録者・日時・公開タグを閲覧できますが、削除と本人限定情報の閲覧はできません。

## 主なファイル

- `Index*.html`: 3言語の画面
- `map.css`: 地図と詳細カード
- `map.js`: GPS、記録、表示、API連携
- `osm-browser-matcher.js`: OSM Way上の経路推論
- `async-record-queue.js`: 永続送信・取消しキュー
