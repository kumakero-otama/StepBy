# UI10 道情報投稿画面

最終確認日: 2026-08-18

地図で選んだ地点または現在地について、StepBy内だけで扱う道情報を投稿します。

現在の機能:

- Leafletによる投稿地点表示と現在地追従
- PostgreSQLのタグマスターを`/api/post-tags`から取得
- タグ検索と新しいタグの追加
- 説明文、カメラ/ライブラリ画像、プレビュー
- `/api/config`の上限に合わせた画像圧縮・サイズ確認
- `/api/road-info`への保存
- 大きい送信や画面遷移に備えたバックグラウンド/永続キュー
- 3言語と共通の表示設定

URLの`lat`、`lng`があれば投稿地点へ反映します。道情報、写真、説明文はOSMへ送信せず、StepByのPostgreSQLとアップロード領域に保存します。
