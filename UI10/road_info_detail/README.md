# UI10 道情報詳細画面

最終確認日: 2026-08-18

地図上の道情報から`pointId`付きで遷移し、`GET /api/road-info?pointId=...`で詳細を取得します。

現在の機能:

- タグ、投稿者、日時、説明文、画像の表示
- 同じ地点へのコメント・タグ・画像追加
- 画像の選択、圧縮、プレビュー、個別削除
- 投稿者本人に限った道情報地点の削除
- 3言語、共通アプリバー、表示設定、バージョン表示
- 履歴または地図画面へ戻る処理

主なファイル:

- `Index*.html`: 3言語のDOM
- `road_info_detail.css`: 投稿カード、モーダル、操作ボタン
- `road_info_detail.js`: 認証、取得、描画、追記、削除

道情報はStepByのPostgreSQLへ保存し、OSMには送信しません。
